Sales & Revenue Exploratory Analysis

Python • Pandas • SQL

The Problem: Raw sales and customer order logs usually come with messy dates, missing product labels, duplicate rows, and outlier prices that make it difficult to trust month-over-month revenue figures.

What I Built: I wrote a Python script using Pandas to automatically clean up the dataset—filling in missing data, removing duplicates, and filtering out erroneous price points. Then, I used SQL queries (including window functions like LAG and running totals) to track revenue growth by product category and examine customer buying habits.

The Results: Reduced manual data cleanup work by about 60%, delivering a clean dataset and charts that clearly showed which product lines were driving the most repeat sales.

# 1. Advanced SQL Window Transformation: Monthly Growth & Running Totals
SELECT order_date, category,
  SUM(revenue) AS total_rev,
  LAG(SUM(revenue)) OVER (PARTITION BY category ORDER BY order_date) AS prev_rev,
  ROUND(100.0 * (SUM(revenue) - LAG(SUM(revenue)) OVER (PARTITION BY category ORDER BY order_date)) / LAG(SUM(revenue)) OVER (...), 2) AS mom_growth_pct
FROM transactions_staging GROUP BY 1, 2;
