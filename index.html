Multi-Channel Sales ETL & Revenue Analytics Pipeline

PySpark • Python • SQL • BigQuery / Cloud Storage

The Problem: When multi-channel sales and ad revenue exports were dumped daily from web storefronts and ad servers, they suffered from corrupt timestamps, duplicate order transactions, unformatted refund subtractions, and null customer identifiers—distorting actual net revenue and rolling MoM growth figures.

What I Built: I built an end-to-end PySpark batch ingestion and transformation notebook. It reads multi-source raw dumps, validates schemas, catches data anomalies, normalizes refund records, and runs window functions (like rolling 7-day moving averages and revenue deltas) before partitioning and writing clean data into Google Cloud BigQuery.

The Results: Cut manual spreadsheet wrangling time by ~60%, eliminated duplicate transaction discrepancies, and produced an automated, audit-ready data mart consumed directly by BI dashboards.

# Pipeline Step 1: Dedup, sanitize timestamps, handle refund anomalies
df_clean = (df_orders_raw
  .dropDuplicates(["order_id", "transaction_ts"])
  .withColumn("order_date", F.to_date(F.col("transaction_ts")))
  .withColumn("customer_id", F.coalesce(F.col("customer_id"), F.lit("GUEST_CHECKOUT")))
  .withColumn("net_revenue", F.when(F.col("status") == "REFUNDED", -F.abs(F.col("amount"))).otherwise(F.col("amount")))
  .filter(F.col("amount") > 0))

print(f"Raw records: {df_orders_raw.count():,} | Clean records: {df_clean.count():,}")
df_clean.select("order_id", "order_date", "channel", "customer_id", "net_revenue", "status").show(5, truncate=False)

# Pipeline Step 2: 7-day rolling window & write to BigQuery partitioned table
channel_window = Window.partitionBy("channel").orderBy("order_date").rowsBetween(-6, 0)
df_final = (df_clean.groupBy("channel", "order_date")
  .agg(F.sum("net_revenue").alias("daily_rev"), F.count("order_id").alias("orders"))
  .withColumn("rolling_7d_rev", F.round(F.avg("daily_rev").over(channel_window), 2)))

(df_final.write.format("bigquery")
  .option("table", "analytics_warehouse.fct_daily_revenue_mart")
  .option("partitionField", "order_date")
  .mode("append").save())
